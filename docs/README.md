# Amber Documentation

Documentation for the **October Amber** library, written for Laravel developers using Amber
standalone, outside of any CMS.

The docs lead with a Laravel narrative — install, then render a form, a list, and a filter from a
controller — and fold the per-type reference into combined pages.

| Page | Covers |
|------|--------|
| [getting-started.md](getting-started.md) | What Amber is, the sixty second example, how it fits together |
| [installation.md](installation.md) | Requirements, composer, asset publishing, layout setup |
| [forms.md](forms.md) | The Form widget and all field, UI and widget types |
| [lists.md](lists.md) | The List widget, column types, and the ListStructure variant |
| [filters.md](filters.md) | The Filter widget and all scope types |
| [toolbar.md](toolbar.md) | The Toolbar widget — buttons and search |
| [ui.md](ui.md) | The `Ui` facade — buttons, inputs, dropdowns, callouts |
| [eloquent.md](eloquent.md) | Using Amber with plain Eloquent models |
| [ajax.md](ajax.md) | How Amber widgets behave as Larajax view components |
