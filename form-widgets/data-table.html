Data Table ​

The datatable field edits a list of rows in a spreadsheet grid, built on Hotsheet (the library's own data grid). It saves the rows as a JSON list of objects keyed by column name, so cast the attribute with 'array' or 'json' (or list it in $jsonable on an October Rain model). Rows with no values are left out when saving.

Columns ​

columns lists the columns by the key they save under. Each takes a title (the key when left out) and a type:

  • string, the default, plain text.
  • numeric, a number.
  • checkbox, saved as 1 or 0.
  • dropdown and autocomplete, see Dropdowns.
  • date and time, see Dates and times.

Insert Row adds a row at the end, and Delete Row removes the selected row (or the last one when none is selected). An empty table starts with one blank row, and column edges can be dragged to resize them.

yaml
fields:
    line_items:
        label: Line Items
        type: datatable
        comment: Rows save as a JSON list, one object per row keyed by column name.
        columns:
            item:
                title: Item
            quantity:
                title: Qty
                type: numeric
                width: 90px
            price:
                title: Unit Price
                type: numeric
                width: 120px
            taxable:
                title: Taxable
                type: checkbox
                width: 90px

The grid works like a spreadsheet from the keyboard. Arrow keys, Tab and Enter move between cells, typing replaces a cell, Enter or F2 edits it, Escape cancels an edit, and Delete clears the selection. Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z and Ctrl+Y copy, cut, paste, undo and redo, also between the grid and a spreadsheet. Alt+A adds a row below the selected one, Alt+Shift+A above it, and Alt+D deletes it. A right click opens a menu for inserting and removing rows.

To give new rows default values, listen for the datatable:new-row event, which fires for each row added with the row object as event.detail.row, and set its keys.

Dates and times ​

Date and time cells open a picker. dateFormat (YYYY-MM-DD by default) and timeFormat (HH:mm by default) set both the shown and the saved text, so timeFormat: 'h:mm A' shows and saves a twelve hour time such as 2:30 PM.

yaml
fields:
    deliveries:
        label: Deliveries
        type: datatable
        comment: The date and time cells open a picker, and the Until column uses a twelve hour clock.
        columns:
            date:
                title: Date
                type: date
                width: 140px
            from:
                title: From
                type: time
                width: 110px
            until:
                title: Until
                type: time
                timeFormat: 'h:mm A'
                width: 110px
            carrier:
                title: Carrier

Dropdowns ​

A dropdown column lists every option and must be one of them. It saves the key of the option picked and shows its label. An autocomplete column narrows its options as you type and also accepts other text: picking an option saves its key, and other text saves as typed. Both take options as a map of keys to labels.

yaml
fields:
    variants:
        label: Variants
        type: datatable
        comment: Finish must be one of its options, while Shade Color suggests options and accepts any text.
        columns:
            sku:
                title: SKU
                width: 120px
            finish:
                title: Finish
                type: dropdown
                options:
                    brass: Brushed Brass
                    chrome: Polished Chrome
                    matte: Matte Black
            color:
                title: Shade Color
                type: autocomplete
                options:
                    white: White
                    sage: Sage
                    terracotta: Terracotta

Options from the model ​

A dropdown or autocomplete column without options asks the model for them, through the field's onGetDropdownOptions handler. The field calls a method named after it, get{FieldName}DataTableOptions($column, $rowData), or else getDataTableOptions($fieldName, $column, $rowData), which return the options as keys mapped to labels. $rowData holds the row's current values.

dependsOn names another column (or a list of them) the options follow: changing the country clears the city of that row and loads the cities again. So that saved values show their labels straight away, the field also calls the method while rendering, once for each set of dependsOn values among the saved rows, and the grid only asks over AJAX for values it hasn't seen.

yaml
fields:
    stockists:
        label: Stockists
        type: datatable
        comment: The cities follow the country picked in the same row.
        columns:
            name:
                title: Store
            country:
                title: Country
                type: dropdown
                width: 150px
                options:
                    au: Australia
                    nz: New Zealand
                    us: United States
            city:
                title: City
                type: dropdown
                dependsOn: country
                width: 150px
            channel:
                title: Channel
                type: autocomplete
                width: 130px
php
/**
 * getStockistsDataTableOptions returns the options of the stockists table's AJAX columns, where the cities follow the row's country.
 *
 * @param  array<string, mixed>  $rowData
 * @return array<string, string>
 */
public function getStockistsDataTableOptions(?string $column, array $rowData = []): array
{
    if ($column === 'channel') {
        return ['retail' => 'Retail', 'online' => 'Online', 'wholesale' => 'Wholesale'];
    }

    if ($column === 'city') {
        return array_merge([], ...array_column(static::listRegions()[$rowData['country'] ?? ''] ?? [], 'cities'));
    }

    return [];
}

Validation ​

A column's validation lists rules, checked in order, and each takes an optional message:

  • required, the cell must have a value.
  • integer and float, whole or decimal numbers, positive unless allowNegative is set, with min and max.
  • length, the text length, with min and max.
  • regex, the text must match pattern, with optional modifiers.

min and max each take value and an optional message. Every rule also takes requiredWith, a column name that applies the rule only when that column of the row has a value. Empty cells only fail required.

Invalid cells are marked as you edit. With requireValid, saving stops at the first invalid cell of a row that has values, which is selected and its message flashed. A request counts as saving when its handler is the form's own data-request (here onSaveExamples) or is named onSave.

The rules run in the browser, so validate the saved rows on the server as well when they matter.

yaml
fields:
    parts:
        label: Parts
        type: datatable
        requireValid: true
        comment: Save stops at the first invalid cell, which is selected and explained.
        columns:
            name:
                title: Part
                validation:
                    required:
                        message: Name the part.
                    length:
                        max:
                            value: 40
                            message: Keep the name under 40 characters.
            sku:
                title: SKU
                width: 120px
                validation:
                    regex:
                        pattern: '^[A-Z]{2}-\d{3}$'
                        message: Use two capitals, a dash and three digits, such as LP-104.
            quantity:
                title: Qty
                type: numeric
                width: 80px
                validation:
                    integer:
                        min:
                            value: 1
                        max:
                            value: 99
            weight:
                title: Weight (kg)
                type: numeric
                width: 110px
                validation:
                    float:
                        allowNegative: false
            supplier:
                title: Supplier
                validation:
                    required:
                        requiredWith: weight
                        message: A weighed part needs a supplier.

Fixed rows ​

adding: false and deleting: false remove the row buttons, shortcuts and menu items. With nothing left to show, the toolbar is left out too. A column's readOnly locks its cells.

yaml
fields:
    price_breaks:
        label: Price Breaks
        type: datatable
        adding: false
        deleting: false
        comment: The three rows can be edited, but none can be added or removed.
        columns:
            from_quantity:
                title: From Qty
                type: numeric
                readOnly: true
                width: 110px
            discount:
                title: Discount (%)
                type: numeric

Without the toolbar ​

toolbar: false hides the toolbar, while rows can still be added and removed from the right click menu or with Alt+A, Alt+Shift+A and Alt+D.

yaml
fields:
    bundle_items:
        label: Bundle Items
        type: datatable
        toolbar: false
        comment: Right click a row, or press Alt+A and Alt+D, to add and remove rows.
        columns:
            item:
                title: Item
            quantity:
                title: Qty
                type: numeric
                width: 90px

Search, export and import ​

searching adds a search box that highlights the cells containing the text.

csvExport adds an Export button that downloads the rows as a CSV file named after the field, through the field's onExportCsv handler. The header row holds the column titles, and values a spreadsheet would read as a formula are prefixed with an apostrophe.

csvImport adds an Import button that reads a CSV file through onImportCsv and appends its rows. The file may be separated by commas, semicolons or tabs. A header row is matched to the column titles or names, and without one the values are read in column order.

yaml
fields:
    suppliers:
        label: Suppliers
        type: datatable
        searching: true
        csvExport: true
        csvImport: true
        comment: Search highlights the matching cells, Export downloads the rows as CSV, and Import adds the rows of a CSV file.
        columns:
            name:
                title: Name
            contact:
                title: Contact
            email:
                title: Email
            lead_days:
                title: Lead Days
                type: numeric
                width: 110px

Sorting and moving ​

sorting sorts by a column when its header is clicked, for viewing only: the rows save in their own order. reorderRows adds row numbers to drag rows by, which does change the saved order: dragging a row while sorted saves the order you see and clears the sort. reorderColumns lets headers be dragged and frozen, for viewing. multiSelect: false limits the selection to one cell at a time.

yaml
fields:
    components:
        label: Components
        type: datatable
        sorting: true
        reorderRows: true
        reorderColumns: true
        multiSelect: false
        comment: Click a header to sort, drag a row number or a header to move it, and select one cell at a time.
        columns:
            name:
                title: Component
            material:
                title: Material
            weight:
                title: Weight (g)
                type: numeric
                width: 120px

Height ​

Without a height, the table grows with its rows. A height in pixels keeps it that tall, with the rows scrolling inside.

yaml
fields:
    stock_levels:
        label: Stock Levels
        type: datatable
        height: 220
        comment: The rows scroll inside 220 pixels.
        columns:
            warehouse:
                title: Warehouse
            on_hand:
                title: On Hand
                type: numeric
                width: 110px
            reorder_at:
                title: Reorder At
                type: numeric
                width: 110px

Empty state ​

placeholder shows a message while there are no rows, in place of the blank starting row.

yaml
fields:
    reviews:
        label: Reviews
        type: datatable
        placeholder: No reviews yet. Insert a row to add one.
        comment: With no rows, the table shows this message instead of a blank row.
        columns:
            reviewer:
                title: Reviewer
            rating:
                title: Rating
                type: numeric
                width: 90px
            quote:
                title: Quote
                wrap: true

Column options ​

width takes pixels (160px) or a percentage of the table (30%), and columns without one share the space left over. Long text is cut short with an ellipsis, unless the column sets wrap to wrap it over several lines. ellipsis: true states the cut explicitly. readOnly locks the column.

yaml
fields:
    spec_sheet:
        label: Spec Sheet
        type: datatable
        adding: false
        deleting: false
        comment: Locked labels at 30 percent of the width, values that wrap, and notes cut short.
        columns:
            label:
                title: Specification
                readOnly: true
                width: 30%
            value:
                title: Value
                wrap: true
            note:
                title: Note
                ellipsis: true
                width: 160px

Read-only ​

A readOnly field shows the rows without editing them: they can be selected, copied, searched, sorted and exported, and the toolbar drops Insert Row, Delete Row and Import. The value still posts unchanged, where a disabled field, shown the same way, posts nothing.

yaml
fields:
    certifications:
        label: Certifications
        type: datatable
        readOnly: true
        searching: true
        csvExport: true
        comment: The rows can be searched and exported, but not changed.
        columns:
            standard:
                title: Standard
            issued_by:
                title: Issued By
            year:
                title: Year
                type: numeric
                width: 90px

Preview ​

In preview mode the grid shows the rows read-only, as it does for a read-only field. This example's form is made with previewMode on.

yaml
fields:
    awards:
        label: Awards
        type: datatable
        columns:
            award:
                title: Award
            year:
                title: Year
                type: numeric
                width: 90px

Options ​

OptionDescription
columnsthe columns, keyed by the name each saves under, see Column options.
addingallows adding rows. Default: true.
deletingallows removing rows. Default: true.
toolbarshows the toolbar, when it has a button or the search box to show. Default: true.
searchingadds a search box that highlights matching cells. Default: false.
csvExportadds an Export button that downloads the rows as CSV. Default: false.
csvImportadds an Import button that appends the rows of a CSV file. Default: false.
sortingsorts the view by a column when its header is clicked. Default: false.
reorderRowsadds row numbers to drag rows into a new order. Default: false.
reorderColumnslets column headers be dragged and frozen. Default: false.
multiSelectallows selecting a range of cells. Default: true.
heightthe table height in pixels, with the rows scrolling inside. Default: grows with the rows.
placeholdera message shown while there are no rows. Default: one blank row instead.
requireValidstops a save while a row with values has an invalid cell. Default: false.

The field also takes the common field properties, such as readOnly and disabled.

Column options ​

OptionDescription
titlethe header text. Default: the column name.
typestring, numeric, checkbox, dropdown, autocomplete, date or time. Default: string.
optionsthe options of a dropdown or autocomplete column, as keys mapped to labels. Default: asks the model.
dependsOnanother column, or a list of them, whose changes clear this cell and reload its model options.
widththe width in pixels (100px) or a percentage of the table (20%). Default: a share of the space left.
readOnlylocks the column. Default: false.
wrapwraps long text over several lines. Default: false.
ellipsiscuts long text short with an ellipsis, as columns without wrap do. Default: false.
dateFormatthe shown and saved format of a date column. Default: YYYY-MM-DD.
timeFormatthe shown and saved format of a time column. Default: HH:mm.
validationthe rules checked in the browser, see Validation.
