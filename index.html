AmberForm, List and UI tools for Laravel

Build data-driven interfaces from YAML configuration. The widget engine behind October CMS, packaged for any Laravel app.

Getting Started
Installation
GitHub

Forms

Build data-editing forms from a fields.yaml definition bound to a model, with validation and uploads wired through AJAX.

Lists

Render sortable, paginated, searchable record tables from a columns.yaml definition, including tree and reorderable variants.

Filters

Add scope-based filtering (checkboxes, switches, dropdowns) that persists in the session and constrains a list query.

Toolbar & UI

Drop in a control bar with buttons and search, or render individual buttons, inputs and callouts with the Ui facade.

Plain Eloquent

Drive widgets from stock Illuminate Eloquent models. No CMS dependency, no frontend framework, no build step.

Larajax Components

Every widget is a Larajax view component, so AJAX handlers route automatically from the controller that built them.
